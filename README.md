# PayRole

A Philippine-first HRIS for SMEs (50–500 employees): core HR, time and leave, statutory payroll, self-service, and privacy tooling. Multi-tenant, with **multi-role access**: one account per person, many scoped role assignments, enforced separation of duties.

**Status:** pre-build. Documentation baseline v0.2 is ready for owner review; no application code yet.
